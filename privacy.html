Videoloft Workflow - Privacy

Videoloft Workflow is an internal tool used by our review team. This page explains what it does with data.

No data collected

The extension does not collect, sell, share or transfer any personal or usage data. It sends nothing to the developer, to analytics services or to any third party.

Where it runs and what it reads

It works only on app.videoloft.com, partner-app.hungerstation.com and daralesnad.online, inside pages the user is already signed in to. It reads what those pages show (order numbers, times, invoice lines) to help the user review orders.

What it stores

Settings, the pasted order list and caches stay on the user's own computer, in the browser's extension storage.

Network

Its only own connections go to our company's file server (Synology QuickConnect: *.quickconnect.to and *.gofile.me), to check and download the company's own video and invoice files when the user asks. Files the user saves go to the computer's Downloads folder.

Contact

Questions: the review team lead.

الخصوصية

الإضافة أداة داخلية لفريق المراجعة. لا تجمع أي بيانات ولا ترسل شيئًا إلى أي جهة خارجية. تعمل فقط على المواقع الثلاثة أعلاه، وتحفظ إعداداتها على جهاز المستخدم، واتصالها الوحيد هو خادم ملفات الشركة لفحص وتنزيل ملفات الشركة عند الطلب.
